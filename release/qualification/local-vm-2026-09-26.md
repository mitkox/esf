## Checks performed

- Backed up the pre-upgrade factory files, Temporal PostgreSQL databases, and
  Cube MySQL and MinIO state. Restored the Temporal SQL dump into an isolated
  PostgreSQL 16.15 container; the temporal and visibility schema versions were
  1.19 and 1.14. Re-extracted the factory snapshot and confirmed 35 run
  directories and 29 change records. This does not replace a full service and
  QMS recovery drill.
- `make temporal-up temporal-hello` passed. The hello target now includes the
  integration build tag; previously it reported success while running zero
  tests. Legacy Temporal history replay, real-server workflow execution,
  cancellation, timeout cleanup, and the 190-second heartbeat test passed.
- All seven live Cube integration scenarios passed on 0.7.2: create/execute/
  destroy, file round trip, runtime network policy, Git workflow, idempotent
  destroy, template lookup, and metadata recovery.
- A factory conformance run produced a verified patch and left no sandbox.
  Both R2 and R3 assurance integration runs passed, including approval,
  cleanup, and encrypted history replay. A second conformance run on the
  versioned template also passed with no sandbox leak.
- `factory config validate`, the development-profile `factory doctor`, and
  `factory agents verify` passed. Frontend tests passed (40), the Vite build
  passed, and optional Python tests passed (15). The PR's Linux and macOS CI
  checks passed on the initial implementation commit.
- The local conformance script took 24.5 seconds with the old template and
  3.5 seconds with the versioned template. This is an operational observation;
  the deterministic 1/4/8-run benchmark and regression gate remain pending.
- Real OpenCode V2 and Unreal runners launched inside the pinned Cube template.
  OpenCode reached the configured model at `192.168.0.14:8000`, which returned
  HTTP 503 for a 6153-token request and then stopped accepting connections.
  Unreal then failed on a refused connection to the same service. A separate
  disposable configuration tried the responding host endpoint at
  `192.168.0.16:8000`, but Unreal's sandbox could not reach it and timed out.
  All three failed runs reported `AGENT_FAILED` and verified sandbox cleanup.
  These are incomplete model-backed acceptance runs, not passing results.
